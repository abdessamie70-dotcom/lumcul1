# 💡 تطبيق حاسبة الإضاءة المنزلية (Home Lighting Calculator)

تطبيق فلاتر احترافي وحديث لحساب متطلبات الإضاءة المنزلية بدقة هندسية، مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL)، وتصميم Material 3 أنيق ومريح للعين مع سمات فاتحة وداكنة (Light / Dark Themes).

---

## 📐 المعادلات الرياضية المعتمدة (من ملف الإكسل)

1. **المساحة (Area):**
   $$\text{Area} = \text{Length (الطول)} \times \text{Width (العرض)}$$

2. **إجمالي اللومين المطلوب (Total Required Lumens):**
   $$\text{Total Lumens} = \text{Area} \times \text{Required Lux} \times 2$$
   *(معامل 2 يعوض فواقد الامتصاص وانعكاسية الجدران ومعامل الاستخدام والاستهلاك)*.

3. **عدد اللمبات النظري - الدقيق (Nominal Bulbs):**
   $$\text{Nominal Bulbs} = \frac{\text{Total Required Lumens}}{\text{Bulb Lumen}}$$

4. **عدد اللمبات المقترح - العملي (Practical Bulbs):**
   $$\text{Practical Bulbs} = \lceil \text{Nominal Bulbs} \rceil$$
   *(جبر لأقرب عدد صحيح أكبر لضمان تحقيق شدة الإضاءة المطلوبة عملياً)*.

5. **إجمالي استهلاك الطاقة (Total Wattage):**
   $$\text{Total Wattage} = \text{Practical Bulbs} \times \text{Bulb Wattage}$$

## 📱 شاشات وميزات التطبيق

### 1. شاشة حاسبة الإضاءة (Calculator):
- اختيار اسم الغرفة (قائمة منسدلة للغرف الشائعة مع اقتراح تلقائي لشدة الإضاءة المناسبة، أو إدخال اسم مخصص).
- إدخال الأبعاد (الطول والعرض بالمتر).
- إدخال شدة الإضاءة (Lux) مع خيارات سريعة.
- إدخال مواصفات اللمبة (لومين وواط) مع نماذج جاهزة للمبات الـ LED الشائعة (9W, 12W, 15W, Spotlight 7W).
- بطاقة نتائج تفاعلية تعرض: المساحة، اللومين المطلوب، عدد اللمبات العملي والنظري، واستهلاك الواط.
- زر لإضافة الغرفة مباشرة إلى قائمة "مشروع المنزل".

### 2. دليل الإضاءة المعيارية (CIBSE / EN 12464):
- عرض التوصيات الدولية لكل مساحة منزلية:
  - **غرفة النوم:** 100 - 150 Lux | 2700K - 3000K | إضاءة مريحة للعين وتساعد على الاسترخاء.
  - **غرفة المعيشة:** 150 - 200 Lux | 3000K | إضاءة متوازنة مع إمكانية خفت الإضاءة.
  - **المطبخ:** 300 - 500 Lux | 4000K | إضاءة قوية ورؤية واضحة لأماكن التحضير.
  - **المكتب / الدراسة:** 400 - 500 Lux | 4000K - 5000K | تحفيز التركيز وتقليل إجهاد العين.
  - **الحمامات:** 150 - 300 Lux | 3000K - 4000K | مراعاة عزل الرطوبة والماء (IP44 / IP65).
  - **الممرات والمداخل:** 100 - 150 Lux | 3000K | إضاءة ممر آمنة دون توهج.
  - **غرفة الطعام:** 150 - 250 Lux | 2700K - 3000K | تركيز الإضاءة فوق طاولة الطعام.
- زر داخل كل بطاقة لتطبيق المعيار ونقله للحاسبة بضغطة زر واحدة.

### 3. مشروع المنزل التراكمي (Home Project Summary):
- بطاقة إحصائيات للمشروع بأكمله:
  - إجمالي الغرف المضافة
  - إجمالي المساحة (م²)
  - إجمالي عدد اللمبات للبيت بأكمله
  - إجمالي استهلاك الطاقة (واط و كيلوواط)
- قائمة تفصيلية لكل الغرف مع إمكانية حذف أي غرفة أو تفريغ المشروع.
- إمكانية نسخ التقرير الشامل كنص عربي منسق لمشاركته عبر واتساب أو البريد.

## 🚀 طريقة التشغيل (How to Run)

1. الانتقال إلى مجلد المشروع:
```bash
cd lumcal
```

2. جلب الحزم:
```bash
flutter pub get
```

3. تشغيل التطبيق على محاكي، جهاز حقيقي، أو كنسخة سطح مكتب / ويب:
```bash
flutter run
```

4. لتشغيل اختبارات الوحدة والتحقق الرياضي:
```bash
flutter test
```
